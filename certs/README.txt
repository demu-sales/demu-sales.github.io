资质认证 · 文件存放说明
=====================================

一、把文件直接放进这个 certs 文件夹（支持 pdf / jpg / jpeg / png / webp），
    然后运行一次部署脚本，文件会自动出现在网站「资质认证」页面里。

二、建议按下面的格式给文件命名（用两个下划线 __ 分隔三段）：

      名称__类别__关联系列.pdf
      名称__类别__关联系列.png

    示例：
      CE-EMC认证__认证证书__迎春,春暖.pdf
      RoHS检测报告__检测报告__迎春,春暖,中庸.pdf
      ISO9001证书__体系认证__.pdf          （不关联具体系列就留空）
      外观专利证书__专利资质__.jpg

    三段说明：
      · 第1段 名称     ：页面上显示的名字，想怎么起就怎么起
      · 第2段 类别     ：用于页面上的分类筛选，例如 认证证书 / 检测报告 / 体系认证 / 专利资质 / 商标资质
      · 第3段 关联系列 ：用逗号分隔，可以写多个；不写表示"通用"

    不按这个格式命名也能用，页面会显示成"未分类"，只是筛选没那么方便。

三、页面上的「复制」按钮怎么用：
    · PDF 文件  → 复制的是"链接"，粘贴到微信/钉钉聊天里发给客户，客户点开即可查看或下载
      （浏览器无法把 PDF 文件本身放进剪贴板，所以用链接方式，客户体验最好）
    · 图片文件  → 直接复制的是"图片"，粘贴到聊天框就能看到图片本身
    · 也可以点「下载」把文件存到本地，再拖进聊天窗口发送

四、更新清单：每次运行部署脚本都会自动扫描本目录并重建 certs.json，无需手动维护。
    删除文件同理，删掉后再部署一次即可。
